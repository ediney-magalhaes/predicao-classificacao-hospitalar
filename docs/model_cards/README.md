# Model Cards

Documentação de cada versão de modelo seguindo o padrão Google Model Cards.

## Convenções

- Uma model card por versão promovida a champion
- Nome do arquivo: `MC-grupo-sus-vN.N.md` e `MC-complexidade-sus-vN.N.md`
- Seções obrigatórias: dados de treino, métricas por subgrupo, limitações, vieses conhecidos, casos de uso pretendidos e proibidos

## Model Cards Existentes

- `MC-grupo-sus-v6.0.0.md`
- `MC-complexidade-sus-v6.0.0.md`

Criadas a partir do relatório de performance de março/2026 (última e até agora única versão treinada). Versionamento estruturado e comparação automática champion vs challenger ficam para a Fase 5.
